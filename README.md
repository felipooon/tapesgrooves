## 🌟 La Experiencia

**Tapes & Grooves** recrea el ritual físico del *Crate Digging* (revolver cajones de vinilos, cassettes y CDs) combinando la calidez analógica de los años 90 con el poder de las APIs de streaming modernas.

1. **🚪 La Entrada (Primera Persona)**:
   * Vista exterior nocturna de la disquería con vitrinas y luces de neón (*OPEN / ABIERTO*).
   * Al cruzar la puerta, suena una campanilla melódica de latón sintetizada en tiempo real.
2. **🏪 El Mostrador & El Disquero**:
   * Atmósfera cálida con posters clásicos y siseo de vinilo analógico (*vinyl crackle*).
   * **Selector de Estados de Ánimo**: Pídele al disquero música según cómo te sientas (*Corazón Roto, Adrenalina, Fiesta Retro, Lluvia/Café, Viaje Mental o Bohemia Latina*).
3. **📦 La Batea 3D (Cajón de Tesoros)**:
   * Perspectiva física de un cajón de madera con lomos táctiles de CDs y cassettes.
   * **12 Universos Musicales** o barra de búsqueda para explorar **cualquier artista o banda del planeta**.
   * Botón *"🎲 SACAR UNO AL AZAR"* y *"🔄 TRAER OTRO LOTE"*.
4. **🎧 Vitrina del Álbum & Walkman / Discman Portátil**:
   * Carátula en alta definición (1000x1000px), año, género y reseña editorial.
   * **Walkman SONY WM-EX1** o **Discman D-E305** interactivo con pantalla LCD digital, ecualizador dinámico (VU Meter), botones mecánicos táctiles (*REW, PLAY, STOP, FWD*) y muestra de audio de 30 segundos en streaming.
   * Enlaces directos para escuchar el disco completo en **Spotify**, **Apple Music** y **YouTube**.

## 🚀 Cómo Ejecutar Localmente

No requiere Node.js ni instalaciones complejas; está construido con tecnologías web nativas puras (HTML5, Vanilla CSS3 y JavaScript moderno):

```bash
# Clona el repositorio
git clone https://github.com/felipooon/tapesgrooves.git

# Entra a la carpeta
cd tapesgrooves

# Inicia un servidor web local (por ejemplo con Python)
python -m http.server 8080
```

Abre en tu navegador:
👉 **`http://localhost:8080`**

## 🌐 Tecnologías Utilizadas

* **HTML5 Semántico**: Escenas organizadas (`exterior`, `interior`, `crate`, `inspect`).
* **Vanilla CSS3 Moderno**: Transformaciones 3D (`perspective`, `preserve-3d`), efectos de brillo acrílico y diseño 100% responsivo para móviles y escritorio.
* **Web Audio API**: Motor de síntesis procedural de sonido (campanilla de latón, clack táctil de estuches, motor de rebobinado y siseo de vinilo).
* **Apple iTunes Search & Lookup API**: Acceso en vivo a millones de álbumes, portadas en HD y muestras de audio oficiales.
